# Phase 1 shared contracts (historical)

This document records the original Phase 1 implementation assignments. Its phase limits and file ownership are historical, not current continuation instructions. Read PROJECT_BRIEF.md and docs/HANDOFF.md for the active phase, then docs/ARCHITECTURE.md for the current additive runtime, storage and grading interfaces.

Owner: Astra integrates and reviews. No recursive delegation. App is a local-only Vite + TypeScript workspace (host UI uses DOM, no framework required). Only Phase 1 is implemented. Node 22 is present. Shared package/config/contracts are owned by Astra.

`src/contracts.ts` is the shared interface. Runtime agent exports `createRuntime(container: HTMLElement, onEvent: (event: RuntimeEvent) => void): RuntimeController` from `src/runtime/index.ts`. It creates/replaces a titled sandbox iframe in container. `run(files)` resolves after compilation and mounting, and emits statuses/errors. Worker build times out. Runtime supplies scripts/prepare-runtime.mjs; it creates local vendor payload and WASM assets. Supports HTML scripts/styles, relative JS imports, imported local assets, and React JSX with react + react-dom/client. No remote imports or learner network. Runtime limit enforcement/recovery must be explicit and tested; no claim of adversarial process isolation.

Persistence agent exports `createInitialSession(): Session`, `demos` (Record<DemoId,{title:string;description:string;files:Files}>) from src/data/demos.ts, and `SessionStore` from src/persistence/store.ts. Store API: constructor(storage?: Storage), load(): Session, save(session: Session): Session (increments revision, throws descriptive errors on conflict/failure), subscribe(callback: () => void): () => void, exportSession(session): string, importSession(json): Session if time appropriate. UI edits session in memory then saves debounce; stale tabs block overwrite, offer explicit reload with conflict copy download. Store uses fresh read revision check. Tests mock storage. Demo vanilla has index.html, styles.css, main.js, model.js, assets/mark.svg; sample Todo form and real DOM behavior. React has index.html, styles.css, main.jsx, App.jsx and counter or task widget. Never auto-overwrite existing files upon switching. Reset current demo only. Checkpoints per workspace.

Content agent owns src/content/**, scripts/validate-content.ts, tests/content.test.ts, docs/CURRICULUM.md. Uses Zod schema with stable IDs, prerequisites and draft/published status. Defines full future Topic contract: interleaved readings/guided coding, conceptual/code blanks, >=20 reviewed distinct question identities in published topics, exactly three ordered challenges, explicit gate, validation/hints/reference. Phase 1 only outline/draft scaffold; no completed lessons and no fake question bank. Outline for four projects with prerequisite chain and teach-before-use ordering. Validator checks global ID/reference correctness, prerequisites DAG and published-topic requirements. Do not implement Phase 2 UI/engine.
